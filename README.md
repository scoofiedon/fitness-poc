# 💪 Фитнес-приложение: Proof of Concept

Proof of Concept приложения для фитнеса с распознаванием некоторых упражнений через веб-камеру.

## 🚀 Функциональность

- 📹 Видео-обучение технике 
- 📖 Текстовое описание с важными моментами
- 🤖 Распознавание позы в реальном времени с помощью MediaPipe Pose
- 🔢 Подсчет повторений 
- 📊 Коррекция правильности выполнения

## 🛠️ Технологии

- Vue 3 + Vite
- MediaPipe PoseLandmarker
- Web Camera API
- GitHub Pages для деплоя

## 🏃‍♂️ Локальный запуск

```bash
npm install
npm run dev
```
